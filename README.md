# LineChatbot

Webchat for a LINE Official Account — receive messages from LINE users, see who sent them, and reply from the browser.

- `apps/web` — Next.js (App Router, SSR)
- `apps/api` — NestJS + Fastify

See [docs/how-it-works.md](docs/how-it-works.md) for the architecture, chat flow, API reference and local setup.
